    🔑 เก็บไฟล์ mapping.json ไว้เอง และห้ามส่งต่อ
    เป็นตารางบอกว่ารหัสไหนคือชื่อจริงอะไร ใครมีไฟล์นี้ก็ย้อนกลับเป็นชื่อจริงได้ ส่วนไฟล์ผลลัพธ์ส่งต่อได้ปลอดภัยกว่า
    ปีหน้านำไฟล์นี้มาใส่พร้อมไฟล์ใหม่ เพื่อให้รหัสเดิมยังเป็นรหัสเดิม
    ชื่อบริษัทเหล่านี้คล้ายกัน เป็นที่เดียวกันหรือไม่?
    ติ๊กเฉพาะคู่ที่เป็นที่เดียวกันจริง (ค่าเริ่มต้นคือไม่รวม) แล้วกดแปลงใหม่ ระบบจะจำไว้ใน mapping.json ให้

    จัดกลุ่มอาชีพ

    แต่ละอาชีพในข้อมูล → อยู่ในหมวดอะไร → หมวดนั้นอยู่ในกลุ่มไหน ระบบแนะนำให้ก่อน แก้ได้ตามที่เจ้าหน้าที่/ผู้ใช้เห็นว่าเหมาะสม (เปลี่ยน “กลุ่ม” = เปลี่ยนกลุ่มของหมวดนั้นทั้งหมด เพิ่มหมวด/กลุ่มใหม่ได้จากตัวเลือกท้ายรายการ) แถวสีเหลืองคือที่คุณแก้ ระบบจะจำไว้ใน mapping.json ชื่ออาชีพที่เห็นในหน้านี้แสดงเฉพาะบนจอของคุณ

    อาชีพ→ หมวด (category)→ กลุ่ม (group)สถานะ

    ไม่พบคอลัมน์ตำแหน่งงานในตารางที่เลือก จึงไม่มีอะไรให้จัดกลุ่ม ข้ามไปขั้นถัดไปได้เลย

    จัดกลุ่มอาชีพเสร็จแล้ว ✓

    ตารางด้านล่างคือผลที่ใช้: อาชีพ → หมวด → กลุ่ม ดาวน์โหลดไว้ใช้ต่อได้ทั้ง CSV และ JSON

    จำนวนคนตามกลุ่ม
