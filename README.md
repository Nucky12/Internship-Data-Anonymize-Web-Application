# แปลงข้อมูลฝึกงานให้เป็น Anonymous

เว็บแอปบนเครื่องตัวเอง (Flask) สำหรับแปลงข้อมูลฝึกงานของนักศึกษาให้ไม่ระบุตัวตน โดยแทนชื่อนักศึกษา บริษัท และอาจารย์นิเทศด้วยรหัส ตัดคอลัมน์ส่วนตัวทิ้ง แล้วจัดกลุ่มตำแหน่งงานเป็นหมวดอาชีพ เพื่อให้เอาข้อมูลไปวิเคราะห์หรือเผยแพร่ต่อได้อย่างปลอดภัยขึ้น

- ไม่มีล็อกอิน ไม่มีฐานข้อมูล
- ไฟล์ที่อัพโหลดถูกประมวลผลใน**หน่วยความจำล้วนๆ** ไม่ถูกเขียนลงดิสก์ **เซิร์ฟเวอร์ไม่เก็บอะไรไว้**
- สถานะของแต่ละขั้นตอนอยู่ในหน้าเว็บของผู้ใช้เท่านั้น (รีเฟรชหรือปิดหน้า = เริ่มใหม่)

## 1. โปรเจกต์นี้ใช้ทำอะไร

ข้อมูลฝึกงานของนักศึกษา (ชื่อ รหัส บริษัท อาจารย์ ตำแหน่งงาน ช่วงเวลา) เป็นข้อมูลส่วนบุคคล เอาไปวิเคราะห์หรือทำรายงานตรงๆ ไม่ได้ โปรแกรมนี้ช่วยทำ 3 อย่าง:

| ทำอะไร | รายละเอียด |
|---|---|
| **แทนด้วยรหัส** | รหัสนักศึกษา → `นักศึกษา 1, 2, 3…` / บริษัท → `บริษัท 1, 2, …` / อาจารย์ → `อาจารย์ 1, 2, …` รหัสเดิมคงที่ข้ามปี (ผ่านไฟล์ `mapping.json`) |
| **ตัดข้อมูลส่วนตัวทิ้ง** | คอลัมน์ที่ไม่ได้เลือกเอา (ชื่อ เบอร์โทร อีเมล ที่อยู่ ฯลฯ) ถูกทิ้งทั้งหมด ไม่อยู่ในผลลัพธ์ |
| **จัดกลุ่มอาชีพ** | ตำแหน่งงานที่เขียนอิสระ → หมวด (category) → กลุ่ม (group) เช่น "Flutter Dev" → Mobile Developer → กลุ่มพัฒนาซอฟต์แวร์ นอกจากนี้ยังคำนวณเดือนและปีที่ฝึกงานให้ |

ผลลัพธ์สุดท้ายคือไฟล์รวม `all_anonymized.csv/.json` ที่เอาไปทำ dashboard (เช่น Power BI) หรือวิเคราะห์ต่อได้ รวมข้อมูลหลายปีเข้าด้วยกันได้

## 2. เริ่มเร็ว (สำหรับเจ้าหน้าที่)

1. แตก zip ให้เรียบร้อยก่อน (คลิกขวา → Extract All) **ห้ามดับเบิลคลิกจากในไฟล์ zip**
2. เปิดโฟลเดอร์ `anonymize-web` ดับเบิลคลิก **`run.bat`** (ครั้งแรกรอสักครู่ ระบบติดตั้งของที่จำเป็นให้เอง)
3. เบราว์เซอร์เปิดที่ `http://localhost:5000` (ถ้าไม่เปิดเอง ให้พิมพ์ที่อยู่นี้เอง)
4. ลากไฟล์ข้อมูลฝึกงาน (.xlsx / .csv) ใส่ → กดถัดไป → ติ๊กตาราง → กดแปลง
5. **ดาวน์โหลด `mapping.json` แล้วเก็บไว้ 2 ที่** (ห้ามส่งต่อ ห้ามทำหาย)
6. เสร็จแล้วปิดหน้าต่างสีดำ

> ⚠ ห้ามปิดหน้าเว็บ/รีเฟรช ก่อนดาวน์โหลดผลและ `mapping.json` เพราะทุกอย่างอยู่ในหน้านั้นเท่านั้น

## 4. การติดตั้ง

### 4.1 Windows แบบออฟไลน์ (แนะนำ ใช้ได้แม้เครือข่ายบล็อก PyPI)
โฟลเดอร์ `wheels/` มีแพ็กเกจที่ต้องใช้ครบสำหรับ Python 3.10, 3.11, 3.12, 3.13 (Windows 64 บิต) รวม 26 ไฟล์

1. แตก zip โปรเจกต์ → ได้โฟลเดอร์ `anonymize-web`
2. ตรวจว่ามีโฟลเดอร์ `anonymize-web\wheels\` อยู่ข้าง `run.bat` (ถ้าได้ชุด `wheels_py3xx.zip` แยกมา ให้แตกทุกไฟล์ลงโฟลเดอร์ `anonymize-web` เดียวกัน ตอบ "Replace" เมื่อถามไฟล์ซ้ำ)
3. ดับเบิลคลิก `run.bat`

`run.bat` ทำให้อัตโนมัติ: เช็กว่าแตก zip แล้ว → เช็กว่ามี Python → สร้าง `.venv` → ติดตั้งจาก `wheels` (ถ้าไม่ผ่านจะลองโหลดจากอินเทอร์เน็ตแทน) → หาพอร์ตว่าง (เริ่ม 5000 ถึง 5010) → เปิดเบราว์เซอร์ → รันโปรแกรม

### 4.2 Windows แบบออนไลน์
ไม่ต้องมีโฟลเดอร์ `wheels` ดับเบิลคลิก `run.bat` ได้เลย (ต้องต่ออินเทอร์เน็ตครั้งแรก)

### 4.3 รันเอง (Windows / Linux / macOS)
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
ถ้าติดตั้งแบบออฟไลน์เอง: `pip install --no-index --find-links=wheels -r requirements.txt`

### 4.4 Docker
ดูหัวข้อ [15](#15-ติดตั้งบนเซิร์ฟเวอร์-docker)

### เปิดและปิดโปรแกรม
- เปิด: ดับเบิลคลิก `run.bat` (หน้าต่างสีดำต้องเปิดค้างไว้ระหว่างใช้งาน)
- ปิด: ปิดหน้าต่างสีดำ (หรือกด Ctrl+C)
- ถ้ามีหน้าต่างเก่าค้างอยู่ `run.bat` จะเลือกพอร์ตถัดไปให้เอง ดูที่อยู่ในหน้าต่างสีดำ
- มุมขวาบนของหน้าเว็บเขียนว่า "เวอร์ชัน 2.0 • 6 ขั้นตอน" ถ้าไม่เห็นแปลว่าเปิดโปรแกรมเวอร์ชันเก่าอยู่

## 5. วิธีใช้ทีละขั้น (6 หน้า)

| หน้า | ทำอะไร |
|---|---|
| 1 อัพโหลดไฟล์ | ลากไฟล์ Excel (.xlsx) / CSV มาวาง เลือกได้หลายปีพร้อมกัน **ปีต่อไป** ให้ใส่ `mapping.json` และไฟล์รวมปีก่อน (CSV / JSON / Excel) มาด้วย |
| 2 เลือกตาราง | ติ๊กตารางที่จะแปลง (ดูรายละเอียดด้านล่าง) แล้วกดปุ่มแปลง |
| 3 ผลลัพธ์ anonymize | สรุปผล ตัวอย่างข้อมูล ดาวน์โหลด CSV/JSON และ `mapping.json` ถ้าพบชื่อบริษัทคล้ายกันให้ติ๊กรวมเฉพาะคู่ที่เป็นที่เดียวกัน |
| 4 จัดกลุ่มอาชีพ | ตาราง **อาชีพ → หมวด → กลุ่ม** ระบบแนะนำให้ แก้ได้ทุกช่อง เพิ่มหมวด/กลุ่มใหม่ได้ |
| 5 ผลการจัดกลุ่ม | ตารางอาชีพ→หมวด→กลุ่ม พร้อมจำนวนคน ดาวน์โหลด CSV/JSON |
| 6 ผลรวม | ข้อมูล anonymize + หมวด/กลุ่มอาชีพ (ต่อกับข้อมูลปีก่อนถ้าใส่ไฟล์รวมมา) ดาวน์โหลด CSV/JSON |

กดที่ชื่อขั้นตอนด้านบนเพื่อย้อนกลับไปแก้ได้ (ถ้ากลับไปแก้ตารางแล้วแปลงใหม่ ผลของขั้นหลังจากนั้นต้องทำใหม่)

### หน้า 2 เลือกตารางโดยละเอียด
- แต่ละตาราง = หนึ่งบรรทัด: ช่องติ๊ก • ชื่อชีต • จำนวนแถว • ป้ายสถานะ • ลิงก์ปรับคอลัมน์
- ตารางที่ระบบอ่านออก (ป้าย **✓ พร้อม**) ถูกติ๊กไว้ให้แล้ว แต่ยังไม่แปลงจนกว่าจะกดปุ่ม
- ตารางที่ระบบเดาคอลัมน์ให้ (ป้ายสีส้ม "ควรตรวจ") ไม่ถูกติ๊กให้ ควรกด "ตรวจ / เลือกคอลัมน์" ดูก่อน
- ตารางที่ระบบอ่านไม่ออก (เช่นชีตสรุป ชีตงบประมาณ) ถูกพับไว้ใน "ตารางอื่น" ปกติไม่ต้องใช้
- ถ้ามีหลายไฟล์ จะแยกหัวข้อตามชื่อไฟล์ มีปุ่ม "เลือกทั้งหมดที่พร้อม / ไม่เลือกเลย"
- แถบด้านล่างบอกจำนวนตารางและแถวที่เลือก ปุ่มแปลงจะกดได้เมื่อทุกตารางที่เลือกมีคอลัมน์ "รหัสนักศึกษา"
- "ตัวเลือกเพิ่มเติม" (พับอยู่): เก็บชื่ออาชีพเดิมไว้ในผลลัพธ์ด้วย (ค่าเริ่มต้นไม่เก็บ เพราะชื่ออาชีพบางครั้งบอกชื่อบริษัทได้)

**เมื่อกด "ดู/ปรับคอลัมน์"** จะเห็นรายการ **คอลัมน์ที่จะเอา / ไม่เอา** พร้อมตัวอย่างค่า (แสดงบนจอคุณเท่านั้น ไม่ถูกเก็บ)
- ติ๊กออก = ไม่เอา, ติ๊กเพิ่ม = เอาคอลัมน์ใหม่
- ต้องมีอย่างน้อย 1 คอลัมน์เป็น "รหัสนักศึกษา" (ใช้บอกว่าแต่ละแถวคือใคร) นอกนั้นจะเอาหรือไม่เอาก็ได้
- **ระบบรู้จัก** (จัดการพิเศษให้): รหัสนักศึกษา / บริษัท / อาจารย์นิเทศ (แปลงเป็นรหัส), วันเริ่ม-วันสิ้นสุด หรือช่วงเวลา (คำนวณเดือน-ปีให้), ตำแหน่งงาน (จัดหมวดอาชีพให้), จังหวัด, รายวิชา, MOU
- **คอลัมน์อื่นที่อยากเพิ่ม:** ติ๊กเอา แล้วเลือก "เก็บไว้ตามเดิม" (ตั้งชื่อคอลัมน์ในผลลัพธ์ได้) หรือ "แปลงเป็นรหัส" (ตั้งคำขึ้นต้นรหัสได้ เช่น "ผู้ประสานงาน 1, 2, 3…" รหัสถูกจำไว้ใน `mapping.json` ใต้ `_codes`)
- คอลัมน์ที่น่าจะมีข้อมูลส่วนตัว (ชื่อ อีเมล เบอร์โทร ที่อยู่ ลิงก์) มีเครื่องหมาย ⚠ และเมื่อติ๊กเพิ่มจะตั้งเป็น "แปลงเป็นรหัส" ให้ก่อน ถ้าเลือก "เก็บตามเดิม" จะมีคำเตือน (เป็นสิทธิ์ของผู้ใช้ที่จะตัดสินใจ) คอลัมน์ที่น่าจะมีข้อมูลส่วนตัวแสดงตัวอย่างค่าแค่ 2 ตัวแรก
- ปุ่ม "↺ กลับไปใช้ที่ระบบแนะนำ" คืนค่าคอลัมน์ของตารางนั้นเป็นค่าเดิมที่ระบบเลือกให้
- **คอลัมน์ที่ไม่ได้เลือกจะถูกทิ้งทั้งหมด** ไม่อยู่ในไฟล์ผลลัพธ์

### หน้า 3 ผลลัพธ์
- ตารางสรุป: จำนวนแถวต่อตาราง และหมายเหตุที่ควรตรวจกับไฟล์ต้นฉบับ
  - "วันที่ฝึกงานอ่านไม่ได้ N แถว" (ส่วนมากเป็นช่องว่างหรือเขียนวันที่ไม่ครบ)
  - "ข้าม N แถวที่ไม่มีรหัสนักศึกษา" (แถวว่างล้วนไม่นับ)
  - "ข้าม N แถวที่ยังไม่มีที่ฝึกงาน" (เช่นเขียนว่า "กำลังหาที่ฝึกงาน")
- ชื่อบริษัทที่คล้ายกัน (เช่น "ABC จำกัด" กับ "เอบีซี จำกัด") ระบบเสนอให้รวม ติ๊กเฉพาะคู่ที่เป็นที่เดียวกันจริง ผลถูกจำใน `mapping.json` (`_alias`)

## 6. ไฟล์ผลลัพธ์

| ไฟล์ | จากหน้า | เนื้อหา |
|---|---|---|
| `anonymized.csv/.json` | 3 | ข้อมูลที่แทนรหัสแล้ว ยังไม่มีหมวดอาชีพ |
| `position_groups.csv/.json` | 5 | ตารางอาชีพ → หมวด → กลุ่ม พร้อมจำนวนคน (มีชื่ออาชีพเดิมอยู่ด้วย แต่ไม่ผูกกับบริษัทหรือคน) |
| `all_anonymized.csv/.json` | 6 | **ไฟล์รวมสำหรับใช้งานต่อ** |
| `mapping.json` | 3 | **กุญแจย้อนกลับเป็นชื่อจริง เก็บไว้เอง ห้ามส่งต่อ** |

คอลัมน์หลักของ `all_anonymized`:
`source, table, year, student_id, company, advisor, province, course, start, end, months, position_code, position_category, position_group, position_confidence`

- `source` ชื่อไฟล์ต้นทาง, `table` ชื่อชีต, `year` ปีที่ฝึกงาน, `months` จำนวนเดือน
- `position_confidence`: **High** ระบบแนะนำ / **Medium** เดาจากบริบท / **Low** ไม่แน่ใจ / **Manual** คุณแก้แล้ว
- CSV เป็น UTF-8 มี BOM เปิดใน Excel ภาษาไทยได้ ค่าที่ขึ้นต้นด้วย `=` `+` `-` `@` จะมี `'` นำหน้ากัน Excel ตีเป็นสูตร

## 7. mapping.json ไฟล์สำคัญที่สุด

เก็บว่ารหัสไหนคือชื่อจริงอะไร และการตั้งค่าที่คุณแก้ไว้:

| คีย์ | เก็บอะไร |
|---|---|
| `student_id`, `company`, `advisor` | รหัสนักศึกษา/บริษัท/อาจารย์ ↔ ชื่อจริง |
| `_alias` | คู่ชื่อบริษัทที่คุณสั่งรวมกัน |
| `_position` | อาชีพที่คุณจัดหมวดเอง |
| `_taxonomy` | รายการหมวด/กลุ่มที่คุณแก้ |
| `_codes` | รหัสของคอลัมน์ที่คุณเพิ่มเอง (แบบ "แปลงเป็นรหัส") |

**ประโยชน์:** ปีหน้าใส่ไฟล์นี้พร้อมไฟล์ใหม่ รหัสเดิมจะยังเป็นรหัสเดิม (นักศึกษา 5 ยังเป็นคนเดิม) และการตั้งค่าที่คุณแก้ไว้ไม่ต้องทำซ้ำ

**ข้อควรระวัง**
- **ถ้าทำหาย** รหัสปีถัดไปจะเริ่มนับใหม่และต่อกับข้อมูลเก่าไม่ได้ ระบบไม่เก็บสำเนา (ตั้งใจเพื่อความปลอดภัย) **ควรสำรอง 2 ที่**
- **ห้ามส่งต่อ** เพราะใครถือไฟล์นี้ก็ย้อนรหัสกลับเป็นชื่อจริงได้ ไฟล์ไม่ได้เข้ารหัส และเบราว์เซอร์จะเก็บไว้ในโฟลเดอร์ Downloads ให้ย้ายไปเก็บที่ปลอดภัยแล้วลบจาก Downloads
- ไฟล์รวมกับ `mapping.json` ต้องเป็นคู่เดียวกัน (ชุดที่ดาวน์โหลดมาพร้อมกัน) ถ้าไม่ตรง ระบบจะหยุดและแจ้ง
- ถ้าใส่ไฟล์ `.json` ที่ไม่ใช่ `mapping.json` ของระบบนี้ ระบบจะหยุดและแจ้ง (ไม่เริ่มนับรหัสใหม่เงียบๆ)

## 11. ความปลอดภัยและข้อจำกัด

### สิ่งที่ระบบทำให้
- ไฟล์ที่อัพโหลดอยู่ในหน่วยความจำล้วนๆ **ไม่ถูกเขียนลงดิสก์เลย** (ไม่มีไฟล์ชั่วคราว) และ log ของโปรแกรมไม่บันทึกค่าจากไฟล์ (ลงแค่ชนิดของ error)
- เปิดได้เฉพาะ `localhost` (กันเว็บอื่นในเบราว์เซอร์เดียวกันแอบเรียกใช้ — DNS rebinding / CSRF) ถ้าวางหลัง reverse proxy ให้ตั้ง `ALLOWED_HOSTS` และให้ proxy ส่งหัว `Host` เดิมมา
- หน้าเว็บไม่ใช้ `innerHTML` กับข้อมูลจากไฟล์ (กัน XSS) และตั้งหัวความปลอดภัย (CSP, no-store, X-Frame-Options)
- CSV ที่ดาวน์โหลดกัน formula injection (ค่าขึ้นต้นด้วย `= + - @` จะมี `'` นำหน้า)
- ไฟล์ Excel ที่แตกออกมาใหญ่ผิดปกติ (zip bomb) ถูกปฏิเสธ
- คอลัมน์ที่ไม่ได้ติ๊กเอาจะถูกทิ้งทั้งหมด (ชื่อ เบอร์ อีเมล ที่อยู่ไม่ถูกเก็บ เว้นแต่ผู้ใช้ตั้งใจเลือก "เก็บตามเดิม")
- เตือนก่อนปิด/รีเฟรชหน้า เพราะผลและรหัสอยู่ในหน้านี้เท่านั้น

### ข้อจำกัดที่ต้องรู้
- ระบบนี้คือ **pseudonymization** (แทนชื่อด้วยรหัส) **ไม่ใช่ anonymization เต็มรูปแบบ** ผู้ถือ `mapping.json` ย้อนกลับได้ และกลุ่มเล็กมาก (เช่นบริษัทที่มีนักศึกษาคนเดียว) อาจเดาตัวตนได้จากจังหวัด/เดือน/หมวดอาชีพ
- `mapping.json` ไม่ได้เข้ารหัส ต้องดูแลเอง
- ไม่มีระบบล็อกอิน ถ้าเปิดให้คนอื่นเข้าถึงได้ต้องจำกัดเฉพาะเครือข่ายมหาวิทยาลัย/VPN
- ไฟล์ที่ดาวน์โหลดจะอยู่ในโฟลเดอร์ Downloads ของเครื่อง ควรย้ายและลบหลังใช้เสร็จ
- **ควรให้ผู้รับผิดชอบข้อมูลของคณะตรวจเรื่อง PDPA ก่อนใช้งานจริงและก่อนเผยแพร่ผลลัพธ์**

## 14. สำหรับผู้พัฒนา

### โครงสร้างโปรเจกต์
```
anonymize-web/
├── app.py              เว็บ (Flask) + ความปลอดภัย (Host/Origin guard, ไฟล์ในหน่วยความจำ)
├── anonymizer.py       ตรรกะแปลงข้อมูล (อ่านไฟล์ ตรวจคอลัมน์ แทนรหัส จัดกลุ่มอาชีพ)
├── taxonomy.json       หมวด/กลุ่ม/กติกาแนะนำอาชีพ
├── templates/index.html  หน้าเว็บทั้ง 6 ขั้นตอน (ไฟล์เดียว HTML+CSS+JS ไม่มี framework)
├── requirements.txt    flask, pandas, openpyxl, waitress (ล็อกช่วงเวอร์ชัน)
├── run.bat             ตัวเปิดสำหรับ Windows
├── wheels/             แพ็กเกจติดตั้งออฟไลน์ (Windows 64 บิต, Python 3.10–3.13)
├── Dockerfile, docker-compose.yml
└── README.md
```

### Endpoint
| เมธอด | พาธ | หน้าที่ |
|---|---|---|
| GET | `/` | หน้าเว็บ |
| GET | `/health` | ตรวจสถานะ (`ok 2.0`) |
| POST | `/analyze` | อ่านไฟล์ → รายการตารางและคอลัมน์ที่ระบบแนะนำ |
| POST | `/anonymize` | แปลงตารางที่เลือก → ผลลัพธ์ + `mapping` |
| POST | `/positions` | รับการแก้หมวด/กลุ่มอาชีพ → อัปเดต mapping |
| POST | `/finalize` | รวมผลสุดท้าย (ต่อกับไฟล์รวมปีก่อน) |

ทั้งหมด stateless: ไม่เก็บอะไรบนเซิร์ฟเวอร์ ฝั่งเบราว์เซอร์ส่งไฟล์ + สถานะมาทุกครั้ง

### ปรับแต่งที่ใช้บ่อย
- **ให้ระบบรู้จักชื่อหัวตารางใหม่อัตโนมัติ:** เพิ่ม pattern ใน `SCHEMA` ของ `anonymizer.py`
- **ค่าที่ไม่ถือว่าเป็นบริษัทจริง** (ถูกข้าม): `NOT_REAL_COMPANY` ใน `anonymizer.py` (ตอนนี้คือ "กำลังหาที่ฝึกงาน")
- **จำนวนแถวหัวตารางตั้งต้น:** `HEADER_ROWS = 3` ใน `anonymizer.py`
- **หมวดอาชีพและคำที่ใช้จับ:** แก้ `taxonomy.json` ได้เลย ไม่ต้องแตะโค้ด
- **ชุดติดตั้งออฟไลน์ใหม่** (เมื่ออัปเดตแพ็กเกจ):
  ```bash
  pip download -r requirements.txt -d wheels --platform win_amd64 --python-version 3.12 --only-binary=:all:
  # ทำซ้ำสำหรับ 3.10 3.11 3.13
  ```

### การทดสอบ
ทดสอบกับ pandas 2.3.3, 3.0.5 และ 3.1.1 (ผ่านทั้งหมด) ครอบคลุม: อัพโหลด → วิเคราะห์ → แปลง → จัดกลุ่ม → รวมผล, CSV แบบ Thai Windows, mapping ขนาดใหญ่, formula injection, zip bomb, Host/Origin guard และการไม่เขียนไฟล์ลงดิสก์ ทดสอบเบราว์เซอร์ด้วย Playwright (Chromium) ยังไม่มีชุดทดสอบอัตโนมัติในโปรเจกต์

- ค่าเริ่มต้นเปิดเฉพาะเครื่องนั้น (`127.0.0.1:5000`)
- **ถ้าจะให้คนอื่นเข้าได้ ต้องวางหลัง reverse proxy แบบ HTTPS และจำกัดให้เข้าได้เฉพาะเครือข่ายมหาวิทยาลัย/VPN** เพราะหน้านี้ไม่มีล็อกอิน และไฟล์ที่อัพโหลดมีข้อมูลจริงของนักศึกษา ไม่ควรวางบนอินเทอร์เน็ตสาธารณะ
- ตั้ง `ALLOWED_HOSTS` เป็นชื่อเว็บที่ใช้เข้า และให้ proxy ส่งหัว `Host` เดิมมา (nginx: `proxy_set_header Host $host;`)
- คอนเทนเนอร์รันแบบ `read_only`, ตัดสิทธิ์ที่ไม่จำเป็น (`cap_drop: ALL`), ไม่ใช่ root, ไม่มี volume (ระบบไม่เก็บข้อมูล)
- มี healthcheck ที่ `/health`

## 16. ประวัติการเปลี่ยนแปลง

- **หน้าเลือกตารางแบบใหม่:** รายการตารางบรรทัดเดียว ซ่อนรายละเอียดคอลัมน์ไว้ก่อน ปุ่มเลือกทั้งหมด แถบสรุปด้านล่าง เอาช่องตั้งจำนวนแถวหัวตารางออก
- **ติดตั้งออฟไลน์:** เพิ่มโฟลเดอร์ `wheels` และให้ `run.bat` ติดตั้งจากโฟลเดอร์นี้ก่อน (ใช้ได้เมื่อเครือข่ายบล็อก PyPI) พร้อมตรวจ Python และการแตก zip
- **แก้บั๊ก:** ติ๊กคอลัมน์รหัสนักศึกษากลับมาแล้วได้บทบาทเดิมคืน (เดิมกลายเป็น "แปลงเป็นรหัส" แบบทั่วไปจนปุ่มแปลงถูกล็อก)
- **ความปลอดภัย:** ไฟล์ดิบอยู่ในหน่วยความจำล้วน, กัน formula injection ใน CSV, กัน zip bomb, Host/Origin guard, log ไม่รั่วข้อมูล, ตรวจ mapping.json ผิดไฟล์, ขยายขีดจำกัดฟอร์มให้ mapping หลายปีผ่านได้, ปรับ Docker ให้ read-only
- **แจ้งผู้ใช้:** บอกจำนวนแถวที่ถูกข้าม, เตือนก่อนปิดหน้าที่ยังไม่ได้ดาวน์โหลด mapping
- **เวอร์ชันแพ็กเกจ:** ล็อกช่วงเวอร์ชันใน `requirements.txt`
